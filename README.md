# ML-classifier-comparison
A comparison of three machine learning classifiers on scikit-learn's handwritten digit datasets. The dataset contains 1,797 images of handwritten digits (0-9), each 8x8 pixels. The goal is to classify each image correctly and work out which model does it best out of three. K Nearest Neighbour, Random Forest and Decision Tree.

The script prints the confusion matrices of each classifier and saves a png in the working directory.

KNN performed best at 97% test accuracy.
